# Palette Code releases

Installer downloads for the Palette Code desktop app (macOS, Windows, Linux).
Get them from https://llm.pltt.dev/download, which always points at the latest release here.

macOS builds are signed with a Developer ID and notarized by Apple. Windows and Linux builds are unsigned.
Each release carries SHA256SUMS and the update feeds (latest-mac.yml, latest.yml, latest-linux*.yml).
